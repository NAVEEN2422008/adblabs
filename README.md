# ADB Labs — Official High-Tech Website & Portal

> **"Building practical technology through research, engineering, prototyping, and real-world experimentation."**

Modern, interactive corporate landing page and product showcase built with **Vite + React 19 + Tailwind CSS**, designed to the high-tech aesthetic standards of **EcoFlow Titan Series** and **itel Energy**.

---

## ⚡ Core Showcases & Features

1. **Interactive Hero & Hardware Schematic**:
   - High-tech interactive vector schematic of the **ADB Labs PS1 Power Station**.
   - Modular Battery Expansion Switcher (Single 6.144 kWh vs. Dual 12.288 kWh module).
   - Interactive hotspot callouts (Pure Sine Inverter, LiFePO₄ Core, MPPT Controller, Quick-Connect Bus).

2. **PS1 Flagship Deep-Dive**:
   - Subsystem architectural tabs: Inverter & Surge Power, LiFePO₄ Chemistry & BMS, Solar MPPT, and Heavy-Duty Enclosure.
   - Comprehensive technical specification matrix.
   - Transparent engineering validation notices.

3. **Commercial Small-Business Packages**:
   - **Shop 1 Standard System**: 1x PS1 (6.144 kWh) + 2x 720W Panels (1.44 kWp).
   - **Shop 2 Expanded Heavy-Duty System**: 1x PS1 + 1x 6.144 kWh Secondary Battery (12.288 kWh) + 4x 720W Panels (2.88 kWp).
   - Categorical solutions for off-grid businesses, home backup, custom battery packs, and field deployments.

4. **Interactive Autonomy & Runtime Calculator**:
   - Real-time power load calculator for food stalls, fish freezers, blenders, waffle irons, lights, and POS terminals.
   - Dynamically calculates operating hours for both 6.144 kWh and 12.288 kWh systems with solar boost buffers.

5. **Field Engineering Case Studies (Chennai Pilots)**:
   - **Besant Nagar Beach Fish Stall**: Commercial off-grid setup replacing diesel generators with 12.288 kWh storage + 2.88 kWp solar.
   - **Small-Business Food & Beverage Kiosk**: High-surge inductive kitchen setup (blenders & waffle irons) on 6.144 kWh + 1.44 kWp solar.

6. **Robotics & AI R&D Division**:
   - Real-time animated LiDAR radar sweep visualization & ROS 2 terminal monitor preview.
   - 4 Core R&D pillars: Kinematics & Simulation, Edge Computer Vision & Perception, Embedded Firmware (STM32/CAN), and Rapid Additive Prototyping.

7. **Robotics & AI Industrial Internship (Draft Program)**:
   - 6-Week simulation-first curriculum roadmap (ROS 2, Gazebo, OpenCV, Nav2 Autonomous Navigation).
   - 18 live mentor-led sessions, accessible without expensive physical hardware.
   - Interactive "Pre-Register / Priority Waitlist" modal.

8. **Direct System Quote & Feasibility Assessment Form**:
   - Custom load profiler and system selector with instant confirmation feedback.

## 🚀 Running Locally

```bash
# Install dependencies (already completed)
npm install

# Start Vite live development server
npm run dev

# Build optimized production bundle
npm run build

# Preview production build
npm run preview
```

Server is currently running live at: **`http://localhost:5173/`**
